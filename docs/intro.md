# Middleware Integration Service - Docs

This documentation covers the Middleware Integration Service: a small Express-based middleware layer providing RBAC/ABAC hooks, session monitoring, backend connectivity, and an extensible email system (Google SMTP relay or AWS SES).

Location: `src/` (TypeScript). Main entry: `src/app.ts`.
